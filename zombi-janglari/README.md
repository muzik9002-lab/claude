# 🧟 Zombi Janglari — So‘nggi Himoya

Android va brauzer uchun oflayn ishlaydigan zombi janglari o‘yini.

## Boshqaruv
Telefon: joystick va 🎯 otish tugmasi.
Kompyuter: WASD yoki strelkalar, sichqoncha bilan nishon, Space yoki sichqoncha orqali otish. P — pauza, R — qayta o‘qlash.

## APK
GitHub Actions → Build Zombi Janglari APK → Artifacts → Zombi-Janglari-APK.
Yoki Java 17 va Android SDK 35 bilan `gradle :app:assembleDebug` buyrug‘ini ishga tushiring.

Brauzerda `app/src/main/assets/index.html` faylini oching.
Debug APK sinov uchun; Play Store uchun alohida release imzosi va AAB talab etiladi.
